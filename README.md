# Abishek S — Developer Portfolio

Personal developer portfolio website for **Abishek S** ([abishek.app](https://abishek.app)).

An editorial, minimal monograph designed with architectural rigor, literary typographic rhythm, and an organic warm palette.

## 🏛️ Website Structure

1. **Home (`#home`):** Masthead, coordinates (`11°00'N 76°57'E`), availability, title, and section index ribbon.
2. **About (`#about`):** Monograph, identity, bio paragraphs with drop cap, and 3 guiding principles.
3. **Education (`#education`):** B.Tech in Computer Science & Engineering (Class of 2024), coursework, and academic focus.
4. **Projects (`#projects`):** Filterable works (OrbitUI, NightOwl, Mappr, Pulseboard) with architecture modal.
5. **Skills (`#skills`):** Languages, Frontend & Architecture, Backend & Systems, and Tools & Practices.
6. **Goals (`#goals`):** Immediate, Mid-Term, and Long-Term engineering horizons.
7. **Contact (`#contact`):** Transmission card, one-click email copy, client-side dispatch generator, and verified social links.
8. **Colophon:** Typesetting specs, palette breakdown, and return-to-summit control.

## ⚙️ Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Compile production build
npm run build

# Preview production build locally
npm run preview
```

All data is centrally configured in [`src/data/portfolioData.ts`](file:///c:/projects/Portfolio/src/data/portfolioData.ts).
